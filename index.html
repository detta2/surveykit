🛰️ Jelajah Peta

Citra satelit seluruh Indonesia. Klik titik mana saja untuk melihat koordinat LatLon + UTM.

Pilih alat di toolbar atas, lalu gambar langsung di peta ini:

  • 📐 Ukur Lahan — gambar polygon batas lahan
  • ⛰️ Profil — gambar garis jalur
  • 🗺️ Kontur — gambar kotak area
  • 📍 Koordinat — konversi LatLon ↔ UTM

Data elevasi: SRTM via AWS Terrain Tiles · citra: Esri · peta: OpenStreetMap.
Hasil bersifat estimasi untuk survei awal.

📍 Konverter Koordinat

Ubah Lintang/Bujur (desimal atau DMS) ↔ UTM. Zona terdeteksi otomatis dari bujur.

LatLon → UTM

UTM → LatLon

📄 Konversi Batch (CSV)

Format: nama;lintang;bujur atau nama;easting;northing;zona (cth zona: 48S).

⛰️ Profil Ketinggian

Klik ikon garis ↗ di kiri peta, lalu gambar jalur langsung di peta. Profil elevasi dihitung dari DEM satelit (SRTM).

Gambar garis di peta untuk membuat profil ketinggian.

🗺️ Kontur Otomatis

Klik ikon kotak ▭ di kiri peta, gambar area langsung di peta. Klik garis kontur untuk lihat elevasinya.

Gambar kotak di peta untuk generate garis kontur.

📐 Ukur Lahan & Cut-Fill

Klik ikon polygon ⬠ di kiri peta, gambar batas lahan langsung di atas citra satelit.

Gambar polygon di atas citra satelit untuk mengukur lahan.
