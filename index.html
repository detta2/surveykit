🛰️ Jelajah Peta

Citra satelit seluruh Indonesia. Klik titik mana saja untuk melihat koordinat LatLon + UTM.

Pilih alat di toolbar atas, lalu gambar langsung di peta ini:

  • 📐 Ukur Lahan — klik sudut-sudut batas lahan, tekan ✓ Selesai
  • ⛰️ Profil — klik 2 titik (A → B)
  • 🗺️ Kontur — tarik kotak daerahnya, kontur langsung jadi
  • 📍 Koordinat — konversi LatLon ↔ UTM

Data elevasi: SRTM via AWS Terrain Tiles · citra: Esri · peta: OpenStreetMap.
