Jelajah Peta

Citra satelit seluruh Indonesia. Cari daerah di toolbar atas (cth: Lahat), atau klik titik mana saja untuk melihat koordinat.

Pilih alat di toolbar atas, lalu gambar langsung di peta ini:

  • Ukur Lahan — klik sudut-sudut batas lahan, tekan ✓ Selesai
  • Profil — klik 2 titik (A → B)
  • Kontur — tandai daerahmu (klik 1x), kotak bisa digeser
  • Koordinat — konversi LatLon ↔ UTM/MGRS/Plus Code/dll

Data elevasi: SRTM via AWS Terrain Tiles · citra: Esri · peta: OpenStreetMap.
Hasil bersifat estimasi untuk survei awal.
